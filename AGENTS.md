# Agent instructions
Follow the [Google Style Guide](https://google.github.io/styleguide/) for the language in use (Python, TypeScript, shell).
Keep diffs surgical: only what the task needs; match existing patterns; no drive-by refactors or scope creep.
Do not commit, push, or publish unless asked; never overwrite `.env` without permission.
After any turn that changes code, end with a suggested git commit message (1–2 sentences, imperative, why over what)—suggestion only unless the user asks to commit.
